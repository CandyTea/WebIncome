# 司机流水查询

项目仓库：`CandyTea/WebIncome`。

在网页直接上传 Excel，网站自动处理后，手机和电脑都能按司机姓名、开始日期和结束日期查询。查看页不提供修改流水功能。

当前部署已取消查看密码：打开网址即可查询流水；只有上传或更新 Excel 需要管理员密码。**任何拿到网址的人都能看到这些流水数据**，请只把网址发给你信任的人。

## 日常怎么用

Windows 上可以直接双击项目目录中的 `Excel同步助手.exe`：点击“选择文件”，选择 `.xlsx`，再选“同步到服务器”或“仅本地预览”，点击“开始同步”。程序会记住选择，运行记录、同步成功和错误提示都显示在窗口内。“停止同步”或关闭助手后停止监测；打开助手本身不会上传文件。

助手会沿用已有的服务器地址和同步令牌，令牌在设置窗口中默认隐藏。点击“保存设置”只保存配置，不上传工作簿。原始 Excel 始终只读，路径保存在 `.local/local-sync.txt` 和 `.local/remote-sync.txt`，不进入 GitHub。使用助手时不要再同时启动旧的同步窗口。

助手依赖项目现有的 `.venv` 运行环境，需要放在项目目录使用。仓库包含界面源码 `desktop/SyncAssistant.cs`，不提交编译后的程序。新电脑安装项目依赖后，在项目根目录运行下面的 Windows PowerShell 命令即可生成助手：

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File tools/build_sync_assistant.ps1
```

生成的 `Excel同步助手.exe.config` 与 `.exe` 放在一起，保留显示缩放设置。界面使用浅色原生 Windows 控件、微软雅黑和自适应布局；高 DPI 配置参考 [Microsoft 的 Windows Forms 说明](https://learn.microsoft.com/en-us/dotnet/desktop/winforms/high-dpi-support-in-windows-forms?view=netframeworkdesktop-4.8)。

本地验证可以直接双击 `本地自动同步.cmd`，保持窗口运行。它监测同目录下的 `全部流水表(1).xlsx`：在 Excel/WPS 中修改并保存后，通常 3–8 秒内自动核验和更新，已打开的查询页也会自动读取新数据，保留姓名和时间筛选。管理页会显示同步状态；文件正在保存、被占用或校验失败时保留旧数据。

仅修改尚未保存的单元格不会同步。需要保存回原来的路径和文件名，另存为其他文件不会改变当前监测目标。原有的网页上传方式也保留；手动上传会立即生效，下次保存监测文件时会以该文件再次更新。

这项自动监测既可以在本机使用，也可以在网站部署到腾讯云后使用。本机运行时双击 `本地自动同步.cmd`；远程使用时双击 `远程自动同步.cmd`，程序会在本地核验 Excel 后把整份工作簿推送到服务器。两种情况都需要这台电脑和同步窗口保持运行，服务器自身无法读取你电脑里的磁盘文件。

远程同步在服务器端使用一条独立的同步令牌，只能上传 Excel，不能读取查询数据，也不需要管理员密码。首次使用前，在服务器 `/etc/webincome.env` 中设置 `WEBINCOME_SYNC_TOKEN`，然后在本机创建 `.local/remote-sync.txt`：

```text
url=http://你的服务器地址:8765
token=与服务器相同的同步令牌
watch=全部流水表(1).xlsx
```

`远程自动同步.cmd` 会读取这个文件。修改并保存 Excel 后通常在数秒内推送；网络中断或服务器暂时不可用时保留本地数据并自动重试，服务器上的上一份有效数据也不会被破坏。

远程同步会直连所配置的服务器地址，避免系统代理转发失败导致 HTTP 502；助手和命令行同步都采用此方式，不改变 Windows 或其他软件的代理设置。

1. 打开管理页，输入管理员密码后点击“上传 Excel”。
2. 选择原始 `.xlsx` 工作簿，点击“上传并更新流水”。
3. 网站读取 `Sheet2!A:Y`，排除姓名为红色的整行，并检查流水计算结果。
4. 点击“查看流水”，输入司机姓名、选择时间段。点开司机查看每日明细。

整个操作只需要 Excel 文件。无需自己导出数据或执行命令。管理员密码用于上传和更新；查看流水不需要密码。上传后的数据保存在服务器，其他设备打开同一网址即可查看。

每次成功上传会替换当前查询数据，日期以本次文件 A:Y 的范围为准。失败时保留上一份成功数据。原始 Excel 发送到服务器解析，处理完成后不长期保存；红色姓名及其流水不会进入查询数据。

## 工作簿要求与导入规则

读取 `Sheet2!A:Y`，A 列为姓名，B:Y 为每日流水，第一行为表头，不导入 Z 列。支持 A1 的 UNIQUE 姓名列表缓存，跳过空姓名及数字 0 占位行。

姓名颜色同时处理 RGB、索引色、主题色及深浅变化；红色姓名整行排除，隐藏行本身不决定是否导入。真实零值与空白保持区分，不将“未记录”补成 0。

只以 Sheet2 为准，不读取或核对“流水表”，工作簿也可以只有 Sheet2。日期读取 B1:Y1，支持“10月19日总流水”这样的表头（无年份时按 2026 年）、完整日期文字和 Excel 日期。流水直接读取 Sheet2 已保存的数值，公式不限定写法、不重新计算，也不与其他表比较。0（包括占位的 0）按 0 显示，空白显示“未记录”。

日期无效或重复、流水包含计算错误、公式缺少已保存的数值时，保留原有网页数据。请在 Excel/WPS 中计算并保存后再上传；原始 Excel 始终不会被修改。

原始工作簿只读，不回写、改名、移动或覆盖。工作簿中的具体姓名、金额、统计报告与运行数据不包含在代码仓库内。

## 电脑、手机适配

查询年份固定为 2026，首次打开默认查看最近 3 天。快捷按钮支持最近 1、3、7、14 天以及自定义最近 N 天，均从北京时间昨日往前计算，不包含今天。例如 10 月 20 日默认查看 19、18、17 日。也可展开“自选起止日期”，用月、日选择框选取，或点“全部数据”查看上传范围。缺少的日期和空白显示“未记录”，不会补成零流水。

跨年后需要更新 `dist/query.mjs` 的 `QUERY_YEAR` 及年份字符串、`tools/export_sheet2.py` 中无年份日期使用的 `DEFAULT_YEAR`，以及对应测试的日期预期，再重新部署。Sheet2 一次覆盖 24 天，新一年的表头确认无误后再上传。

0 流水预警默认按最新数据日期往前连续 7 个自然日判断，每天都有记录且均为 0 才报红；可在“0 流水预警”中自定义连续天数。预警窗口独立于查询时间，即使只查看最近 1 天，也会按完整的连续 7 天记录判断。中间有非零、空白、缺少日期或记录不足时，都不会触发。司机列表显示“连续 N 天 0 流水”，展开后仅预警窗口内的相应零流水日期标红。

排序支持合计从高到低、合计从低到高和按姓名排序；没有已记录流水的司机排在金额排序末尾，空白不会混成真实零值。

查询页只保留卡片模式：一行一位司机，日期从新到旧横排；在对比区域上下滚动时日期行固定，左右滚动时姓名列固定。默认三天适配手机宽度，较长区间可以横向滑动。旧的查看模式设置和网址参数不影响卡片显示。

搜索司机固定在页面最上方，向下浏览时也能随时输入姓名。支持汉字、完整拼音和拼音首字母，均可部分匹配，不区分大小写；例如虚构姓名“王明川”可以输入 `WANGMINGCHUAN`、`WMC` 或 `明川`。拼音中可带空格，常见多音姓氏按姓氏读音识别，“吕”的拼音支持 `lv` / `lü`。点击“收起筛选与合计”会隐藏时间、预警设置和合计流水，搜索框始终保留；卡片日期行固定在搜索框下方。

拼音转换使用随项目分发的 `pinyin-pro 3.29.5`（MIT，许可见 `licenses/pinyin-pro.txt`），在浏览器内完成，无需 CDN 或第三方查询接口。`dist/pinyin-pro.mjs` 已包含字典，部署时一并更新；`tools/vendor_pinyin.py` 可重新生成固定版本，并核验上游 npm 发布包的 SHA-512。无需改动、重新保存或再次上传 Excel。

点击司机姓名后，明细固定显示从北京时间昨日往前的最近 14 天，按日期从新到旧排列，合计按这 14 天计算。明细独立于首页的三天或其他查询范围；关闭后保留原筛选。缺少的日期显示“未记录”，0 照常显示。

点击司机姓名旁的星号可标记关注，星标司机优先显示，组内继续按所选方式排序。星标仅保存在当前浏览器，刷新、更新 Excel 后仍保留；同一司机按姓名生成的稳定编号识别。手机与 Mac 分别保存，清除网站数据会清除星标，不回写 Excel。

使用系统字体和可点击展开的每日明细。手机不用横向拖动 24 列，支持窄屏、横屏、深色模式和键盘操作。

已验证 390、375、360 像素窄屏和桌面浏览器无横向溢出；iPhone Safari、Mac Safari 真机兼容性还需要上线后实机验收。

## 部署现状与代码怎么上服务器

线上已部署在腾讯云 OpenCloudOS 9.6（Python 3.11）：

- 代码：`/opt/webincome`
- 数据：`/var/lib/webincome/current.json`
- 配置：`/etc/webincome.env`（权限 600，含管理员密码和同步令牌，不提交）
- 服务：`webincome.service`，gunicorn 监听 `0.0.0.0:8765`

当前用打包上传的方式更新：在电脑上打包代码，传到服务器解压后重启服务。仓库没有配置 GitHub Deploy Key，服务器访问 GitHub 也不稳定，所以暂时不用 `git pull`；以后要改成拉取方式，先生成只读 Deploy Key 并加到仓库。

TCP 8765 目前已可从外网访问，可直接打开 `http://服务器IP:8765`。这是 HTTP 直连，密码和流水会明文经过公网，适合临时自用；有域名后按 [部署说明](部署说明.md) 接入 Nginx 和 HTTPS，并把监听地址改回 `127.0.0.1`。

原始工作簿、管理员密码、服务器导入后的数据都在 Git 忽略范围内。业务数据存放在代码目录以外，更新代码不会覆盖它。具体安装、更新和备份步骤见 [部署说明](部署说明.md)。

Nginx 是服务器上向手机、电脑提供网页访问的软件。在这个项目里，它把网页请求转给后台，并负责接入 HTTPS。配置一次后，日常只需打开网页上传或查询。[Nginx 官方说明](https://nginx.org/en/docs/http/ngx_http_proxy_module.html)

## 本地运行与检查

需要 Python 3.10 或更新版本。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:WEBINCOME_ADMIN_PASSWORD = '你自行设置的管理员密码'
$env:WEBINCOME_PUBLIC_VIEW = '1'
.\.venv\Scripts\python.exe app.py
```

`WEBINCOME_PUBLIC_VIEW=1` 表示查看流水不需要密码。如果仍想恢复查看密码，把这一行改成 `$env:WEBINCOME_PUBLIC_VIEW = '0'`，并设置 `$env:WEBINCOME_VIEW_PASSWORD = '查看密码'`。

如果需要监测指定文件，可在启动命令后增加 `--watch "E:\Codex project\WebIncome\全部流水表(1).xlsx"`。本地程序启动时开始监测，程序关闭后停止。

打开 `http://127.0.0.1:8765`。本机预览地址只对这台电脑开放；手机访问需要正式部署到服务器。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
node --test tests/query.test.mjs
```

当前共 33 项 Python 测试、28 项前端测试。测试使用程序生成的虚构工作簿，无需原始业务 Excel。覆盖登录、查看与上传权限、只包含 Sheet2 的工作簿、独立读取日期和已保存数值、红色姓名排除、零值与空白、无效日期与计算错误、服务重启后数据保留、远程同步令牌、自动重试与绕过故障代理，以及姓名筛选、日期区间、北京时间最近天数、金额汇总、连续零流水预警、星标排序和十四天司机明细。桌面助手还验证文件路径、服务器设置、本机端口占用保护，以及对测试服务器的实际同步；界面检查覆盖模拟 100%、125%、150%、200% 缩放。

- [GitHub 只读部署密钥](https://docs.github.com/en/authentication/connecting-to-github-with-ssh/managing-deploy-keys)：服务器仅需拉取代码的权限。
