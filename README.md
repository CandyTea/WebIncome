# 司机流水查询

项目仓库：`CandyTea/WebIncome`。

在网页直接上传 Excel，网站自动处理后，手机和电脑都能按司机姓名、开始日期和结束日期查询。查看页不提供修改流水功能。

当前部署已取消查看密码：打开网址即可查询流水；只有上传或更新 Excel 需要管理员密码。**任何拿到网址的人都能看到这些流水数据**，请只把网址发给你信任的人。

## 日常怎么用

本地验证可以直接双击 `本地自动同步.cmd`，保持窗口运行。它监测同目录下的 `全部流水表(1).xlsx`：在 Excel/WPS 中修改并保存后，通常 3–8 秒内自动核验和更新，已打开的查询页也会自动读取新数据，保留姓名和时间筛选。管理页会显示同步状态；文件正在保存、被占用或校验失败时保留旧数据。

仅修改尚未保存的单元格不会同步。需要保存回原来的路径和文件名，另存为其他文件不会改变当前监测目标。原有的网页上传方式也保留；手动上传会立即生效，下次保存监测文件时会以该文件再次更新。

这项自动监测既可以在本机使用，也可以在网站部署到腾讯云后使用。本机运行时双击 `本地自动同步.cmd`；远程使用时双击 `远程自动同步.cmd`，程序会在本地核验 Excel 后把整份工作簿推送到服务器。两种情况都需要这台电脑和同步窗口保持运行，服务器自身无法读取你电脑里的磁盘文件。

远程同步在服务器端使用一条独立的同步令牌，只能上传 Excel，不能读取查询数据，也不需要管理员密码。首次使用前，在服务器 `/etc/webincome.env` 中设置 `WEBINCOME_SYNC_TOKEN`，然后在本机创建 `.local/remote-sync.txt`：

```text
url=http://你的服务器地址:8765
token=与服务器相同的同步令牌
watch=全部流水表(1).xlsx
```

`远程自动同步.cmd` 会读取这个文件。修改并保存 Excel 后通常在数秒内推送；网络中断或服务器暂时不可用时保留本地数据并自动重试，服务器上的上一份有效数据也不会被破坏。

1. 打开管理页，输入管理员密码后点击“上传 Excel”。
2. 选择原始 `.xlsx` 工作簿，点击“上传并更新流水”。
3. 网站读取 `Sheet2!A:Y`，排除姓名为红色的整行，并检查流水计算结果。
4. 点击“查看流水”，输入司机姓名、选择时间段。点开司机查看每日明细。

整个操作只需要 Excel 文件。无需自己导出数据或执行命令。管理员密码用于上传和更新；查看流水不需要密码。上传后的数据保存在服务器，其他设备打开同一网址即可查看。

每次成功上传会替换当前查询数据，日期以本次文件 A:Y 的范围为准。失败时保留上一份成功数据。原始 Excel 发送到服务器解析，处理完成后不长期保存；红色姓名及其流水不会进入查询数据。

## 工作簿要求与导入规则

读取 `Sheet2!A:Y`，A 列为姓名，B:Y 为每日流水，第一行为表头，不导入 Z 列。支持 A1 的 UNIQUE 姓名列表缓存，跳过空姓名及数字 0 占位行。

姓名颜色同时处理 RGB、索引色、主题色及深浅变化；红色姓名整行排除，隐藏行本身不决定是否导入。真实零值与空白保持区分，不将“未记录”补成 0。

当前版式要求：Sheet2 的 B:Y 通过 SUMIF 汇总“流水表”的 F:AC。程序逐格检查缓存与来源合计是否一致，且日期表头应匹配来源日期。结构改变、缺少计算结果或结果不一致时会拒绝更新。请在 Excel/WPS 中计算并保存后再上传。

原始工作簿只读，不回写、改名、移动或覆盖。工作簿中的具体姓名、金额、统计报告与运行数据不包含在代码仓库内。

## 电脑、手机适配

查询年份固定为 2026。快捷按钮支持最近 1、3、7、14 天以及自定义最近 N 天，也可展开“自选起止日期”，直接用月、日选择框选取，不使用日历控件。查询范围包含开始日和结束日。“最近”以已上传数据的最新日期为基准；不会把没有上传的日期补成零流水。

0 流水预警默认按最新数据日期往前连续 7 个自然日判断，每天都有记录且均为 0 才报红；可在“0 流水预警”中自定义连续天数。预警窗口独立于查询时间，即使只查看最近 1 天，也会按完整的连续 7 天记录判断。中间有非零、空白、缺少日期或记录不足时，都不会触发。司机列表显示“连续 N 天 0 流水”，展开后仅预警窗口内的相应零流水日期标红。

排序支持合计从高到低、合计从低到高和按姓名排序；没有已记录流水的司机排在金额排序末尾，空白不会混成真实零值。

查询页提供两种查看方式，在结果上方点“卡片 / 紧凑”即可随时切换，选择会记住并写入网址：

- **卡片**：原有视图，点开司机就地展开每日明细。
- **紧凑**：一行一个司机，只显示姓名、已记录天数和合计；点一行从底部弹出每日明细，关掉后回到原位置。顶部可按“全部 / 预警 / 未记录”分类。

手机上紧凑模式默认收起筛选区，首屏可以直接看到司机列表；需要改条件时点“展开筛选”。

使用系统字体和可点击展开的每日明细。手机不用横向拖动 24 列，支持窄屏、横屏、深色模式和键盘操作。

已验证 375 像素窄屏和桌面浏览器；iPhone Safari、Mac Safari 真机兼容性还需要上线后实机验收。

## 代码怎么上服务器

你原来的方式可以保留：电脑将网站代码 Push 到私有 GitHub 仓库，腾讯云 OpenCloudOS 服务器 Pull 更新。Excel 在网页上传，不需要加入 GitHub。

原始工作簿、管理员密码、服务器导入后的数据都在 Git 忽略范围内。业务数据存放在代码目录以外，更新代码不会覆盖它。具体安装、更新和备份步骤见 [部署说明](部署说明.md)。

Nginx 是服务器上向手机、电脑提供网页访问的软件。在这个项目里，它把网页请求转给后台，并负责接入 HTTPS。配置一次后，日常只需打开网页上传或查询。[Nginx 官方说明](https://nginx.org/en/docs/http/ngx_http_proxy_module.html)

## 本地运行与检查

需要 Python 3.10 或更新版本。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:WEBINCOME_ADMIN_PASSWORD = '你自行设置的管理员密码'
$env:WEBINCOME_PUBLIC_VIEW = '1'
.\.venv\Scripts\python.exe app.py
```

`WEBINCOME_PUBLIC_VIEW=1` 表示查看流水不需要密码。如果仍想恢复查看密码，把这一行改成 `$env:WEBINCOME_PUBLIC_VIEW = '0'`，并设置 `$env:WEBINCOME_VIEW_PASSWORD = '查看密码'`。

如果需要监测指定文件，可在启动命令后增加 `--watch "E:\Codex project\WebIncome\全部流水表(1).xlsx"`。本地程序启动时开始监测，程序关闭后停止。

打开 `http://127.0.0.1:8765`。本机预览地址只对这台电脑开放；手机访问需要正式部署到服务器。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
node --test tests/query.test.mjs
```

测试使用程序生成的虚构工作簿，无需原始业务 Excel。覆盖登录、查看与上传权限、Excel 导入、服务重启后数据保留、损坏文件和失效计算结果的处理、远程同步令牌与自动重试，以及姓名筛选、包含首尾的日期区间、零值与空白、金额汇总、连续零流水预警、排序和紧凑视图分类。
